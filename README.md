📌 Overview
This project demonstrates how to design, query, and analyze an Employee Database using MySQL, SQLAlchemy, Pandas, and Matplotlib. It showcases end‑to‑end workflow:

Database schema creation

Sample employee data insertion

SQL queries for analytics

Python integration for advanced analysis

Visualizations for insights

🗄️ Database Schema
The database consists of the following tables:

Employees: Employee details (ID, name, department, salary, gender, hire date)

Departments: Department information (ID, name, manager)

Attendance: Daily attendance records

Performance: Yearly performance ratings

👉 ER Diagram included in /images/er_diagram.png.

📊 Features
SQL Queries:

Top 5 highest‑paid employees

Average salary by department

Attendance percentage per employee

Employees hired after a given year

Python Analysis:

Salary distribution statistics

Department‑wise salary comparison

Attendance trend analysis

Performance rating visualization

Database: MySQL

Python Libraries: Pandas, SQLAlchemy, Matplotlib
